## 为什么安全如此重要？

汇丰作为全球最大的银行之一，受到严格的监管：
- **中国**：国家金融监督管理总局（原银保监会已于 2023 年并入）、中国人民银行、国家外汇管理局 [修订注：原“银保监会”已于 2023 年机构改革中并入国家金融监督管理总局，此处更新。]
- **英国**：FCA、PRA
- **美国**：美联储、OCC

违规的代价：巨额罚款 + 牌照吊销 + 声誉损失

## 开发人员必须知道的安全原则

### 1. 数据分类

| 级别 | 例子 | 处理要求 |
|------|------|----------|
| **高敏感** | 密码、CVV、指纹 | 加密存储，不可日志 |
| **敏感** | 银行卡号、身份证 | 脱敏显示，审计日志 |
| **内部** | 客户姓名、手机号 | 访问控制 |
| **公开** | 产品信息、公告 | 无特殊要求 |

### 2. 敏感数据处理

```java
// ❌ 禁止：打印敏感信息到日志
log.info("用户密码: {}", password);
log.info("完整卡号: {}", cardNumber);

// ✅ 正确：只记录脱敏信息
log.info("用户登录成功, userId: {}", maskUserId(userId));
```

### 3. 密码安全

```java
// 密码必须加密存储
@Bean
public PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();
}

// 密码验证
public boolean verify(String rawPassword, String encodedPassword) {
    return passwordEncoder().matches(rawPassword, encodedPassword);
}
```

## 合规要求（红线）

### 绝对禁止

```java
// ❌ 禁止：将敏感数据存入Cookie
Cookie cookie = new Cookie("cardNumber", cardNumber);

// ❌ 禁止：URL参数包含敏感信息
https://bank.com/transfer?to=123&amount=10000&card=6222...

// ❌ 禁止：硬编码密码
String password = "admin123"; // 禁止！

// ❌ 禁止：SQL注入
String sql = "SELECT * FROM users WHERE id = " + userId;

// ❌ 禁止：把生产数据拷贝到测试环境
```

### 必须遵守

```java
// ✅ 正确：使用参数化查询
@Query("SELECT u FROM User u WHERE u.id = :id")
User findById(@Param("id") String id);

// ✅ 正确：敏感数据使用POST body
POST /api/transfer
{
  "toAccount": "123",
  "amount": 100
}

// ✅ 正确：敏感数据加密存储
@Encrypt
private String cardNumber;
```

## 身份验证与授权

### 多因素认证 (MFA)

银行系统通常要求：
- 用户名 + 密码
- 手机验证码 / 动态令牌
- 设备指纹

### 权限控制 (RBAC)

```java
// 权限注解
@PreAuthorize("hasRole('USER')")
public Account getAccount(String accountId) {
    // 检查用户是否拥有该账户的访问权限
    if (!accountService.isOwner(currentUserId, accountId)) {
        throw new AccessDeniedException("无权访问此账户");
    }
    return accountRepository.findById(accountId);
}
```

### 会话管理

```java
// 安全Cookie设置
Cookie sessionCookie = new Cookie("SESSION", token);
sessionCookie.setHttpOnly(true);    // 禁止JavaScript访问
sessionCookie.setSecure(true);      // 仅HTTPS传输
sessionCookie.setMaxAge(3600);      // 1小时过期
sessionCookie.setSameSite("Strict"); // CSRF防护
```

## 审计日志（必须记录）

### 关键操作清单

| 操作类型 | 必须记录 |
|----------|----------|
| 用户登录/登出 | ✅ |
| 密码修改 | ✅ |
| 转账/支付 | ✅ |
| 信息查询 | ✅ |
| 权限变更 | ✅ |
| 系统管理操作 | ✅ |

### 日志格式

```java
// 标准审计日志
AuditLog.builder()
    .userId(userId)
    .action("TRANSFER")
    .resource("account:123456")
    .result("SUCCESS")
    .ipAddress("192.168.1.1")
    .timestamp(LocalDateTime.now())
    .details("{\"toAccount\":\"***1234\",\"amount\":1000}")
    .build();
```

### 日志保留要求

- **交易日志**：至少10年
- **登录日志**：至少5年
- **审计日志**：至少7年

## 常见安全漏洞防护

### 1. SQL注入

```java
// ❌ 危险
String sql = "SELECT * FROM users WHERE name = '" + name + "'";

// ✅ 安全
@Query("SELECT u FROM User u WHERE u.name = :name")
User findByName(@Param("name") String name);
```

### 2. XSS攻击

```html
<!-- ❌ 危险 -->
<div>{{userInput}}</div>

<!-- ✅ 安全 -->
<div th:text="${#strings.escapeHtml(userInput)}"></div>
```

### 3. CSRF攻击

```java
// Spring Security配置
csrf().csrfTokenRepository(CookieCsrfTokenRepository.withHttpOnlyFalse())
    .and()
    .addFilterBefore(new CsrfHeaderFilter(), UsernamePasswordAuthenticationFilter.class);
```

### 4. 重放攻击

```java
// 使用一次性Token
public boolean validateToken(String token, String requestId) {
    // 检查Token是否已使用
    if (redisTemplate.hasKey("used-token:" + token)) {
        return false; // 已使用，可能是重放攻击
    }
    // 标记Token为已使用
    redisTemplate.opsForValue().set("used-token:" + token, "1", Duration.ofMinutes(5));
    return true;
}
```

### 发现安全问题怎么办？

1. **立即上报**：告知Tech Lead + 安全团队
2. **不要传播**：不要在非必要群讨论

## 总结

银行系统安全要点：

1. 🔒 **数据分级**：知道什么数据敏感
2. 🛡️ **纵深防御**：多层防护
3. 📝 **审计日志**：关键操作必记录
4. 🚫 **红线意识**：知道什么不能做
5. ⚡ **快速响应**：安全问题立即上报

> 记住：在银行系统里，合规不是可选的，是必须的
