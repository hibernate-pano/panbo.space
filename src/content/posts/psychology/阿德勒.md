## 序章：一个体弱多病的孩子

1870 年 2 月 7 日，奥匈帝国的维也纳郊外，一个名叫阿尔弗雷德·阿德勒（Alfred Adler）的男孩出生了。

他出生时不太健康。他是个早产儿，瘦弱，佝偻病（严重的维生素 D 缺乏症）让他在童年大部分时间里都身材矮小、行动笨拙——他得在四五岁时才学会走路。他还有一个比他大两岁的哥哥，健康、聪明、成绩优异，是"模范儿子"。他还有一个弟弟。两岁时，弟弟夭折——这件事他没有记忆，可他后来把它当成他人生最早的事件之一。

后来他写道，他童年时反复做一个梦——他在夜里梦见自己被丢在了街上，所有人都在忙自己的事，没有人看着他——这个梦伴随了他整个童年。

这是阿德勒后来全部理论的源头：**一个从小就体验到"我不够好"、"我处于弱势"、"我必须证明我自己"的人，把这个体验提炼成了关于全人类的理论。**

他没有说错。所有后来读他的人，都在自己的生活里看到了这个主题。

## 一、自卑与补偿：阿德勒的起点

### 1.1 一个不合时宜的洞见

1907 年，阿德勒已经在维也纳出版了第一本书《器官的自卑感及其生理补偿》（*Studie über die Minderwertigkeit von Organen*）。这本书的论点是反常识的：身体器官的功能不足**不只是**一种缺陷——它同时是发育的驱动力。

> 一个心肺较弱的孩子，会比别的孩子更早、更多地跑、跳、呼吸。**正是因为他弱**，他才会成为运动员。**正是因为他缺**，他才会去补。

这不是一种安慰性的解释。它是一个机制。功能不足产生**自卑感**（Minderwertigkeitsgefühl），自卑感产生**补偿**（Kompensation）的冲动，补偿的冲动产生**成长**。

人不是因为"强大"而成长，是因为"看见了自己的弱"而成长。

### 1.2 心理自卑感的提出

1910 年，阿德勒把这种从身体自卑感开始的洞见，扩展到了心理领域。他在给弗洛伊德主导的"维也纳精神分析协会"做的演讲中正式提出：决定一个人行为的，不是性本能，而是**自卑感与对优越感的追求**。

这一年在维也纳学界是地震。弗洛伊德坐在台下，面色铁青。

但弗洛伊德不是立刻开火。他允许阿德勒继续留在协会，并让他担任"协会副主席"——这是个高抬一手的姿态，也是某种意义上的"留给你最后一点颜面"。

一年后，1911 年，阿德勒把"个体心理学"（Individualpsychologie）正式从弗洛伊德的精神分析里分出去。他带走了一部分成员——亚德勒、福煦、赖希——以及一个崭新的心理学方向。

他在协会之外成立了"自由精神分析协会"（Verein für freie psychoanalytische Forschung），后来改名"个体心理学协会"。

四年后，他与弗洛伊德就再也没有说过话。

### 1.3 究竟什么是"自卑感"

阿德勒意义上的自卑感**不是**羞愧（shame）。也不是自我贬低（self-abasement）。它是一个**发展性的**事实：

> 每一个生命在一开始都是无力的、不成熟的、依赖他人的。这是不可避免的起点。从这个起点开始，**每一个人**都必然在某个时刻意识到自己的有限。

意识到有限 → 感到**不完整** → 感受到某种**拉力**，要填补这个不完整 → 这就是自卑感。

自卑感不是"病"。它是人的常态。它是发展本身的引擎。

> 神经症患者的问题不在于他感到自卑，而在于**他没有用有效的方式补偿自己的自卑感**。

也就是说：**没有自卑感的人是的人，有自卑感但知道如何补偿的人也是健康的人，有自卑感但用"病态"方式补偿的人才是患者。**

### 1.4 补偿的三条路径

阿德勒认为，对自卑感的补偿有三个可能的方向：

```
自卑感
   │
   ├──→ 1. 健康补偿：发展技能、改进能力、追求有意义的成就
   │
   ├──→ 2. 过度补偿：在某一方面极端追求优越（运动健将、学术明星）
   │
   └──→ 3. 退缩 / 病态补偿：放弃努力、用优越感的虚像代替真实的成长
```

第三条路径包括神经症、人格障碍、成瘾等。阿德勒治疗的核心，就是帮助患者从第三条路径回到第一条。

值得记住的是：**第二条和第三条路径在外人看来有时难以分辨。** 一个人拼命工作、把职业推到极端、长期加班——这是健康补偿还是过度补偿还是病态退缩？阿德勒的回答是：**看他的"社会兴趣"（Gemeinschaftsgefühl）。**

这就是阿德勒第二个核心概念，也是他与弗洛伊德分裂的根本点——

## 二、社会兴趣：从性到社会

### 2.1 离开"性"

弗洛伊德把人的根本动力归结为**libido（力比多）**——性的能量。它是本能的、生物学的、个人主义的。

阿德勒的反驳不是"性不存在"。他的反驳是：**性不是根本动力**。性只是人在追求社会意义时的一种**表达方式**。一个人要孩子，可能是因为 ta 想证明自己的成年身份、要完成家族的期待、要延续意义——而**不是因为"性本能被压抑"**。

> 一个人抽烟、酗酒、性乱、孤独地工作——这些都不是因为"力比多的转向"，是因为 ta 没有找到**社会性的意义**。

阿德勒的术语：**社会兴趣**（Gemeinschaftsgefühl；直译"共同体感"），或"社会感"、"社群感"——是指一个人**对自己作为共同体一部分**的觉察与关注。

- 一个有健康社会兴趣的人，关心别人的福祉，关心自己的工作对他人有什么影响。
- 一个缺乏社会兴趣的人，把世界看作**他自己的战场**——其他人都可能是威胁或工具。

> 神经症的本质，不是欲望被压抑，而是**社会兴趣的失败**。

### 2.2 横向 vs 纵向

阿德勒有一个非常实用的区分：**横向关系**与**纵向关系**。

- **横向关系**：我和你并排站着。我们不同，但我们是平等的。
- **纵向关系**：我比你高，或者你比我高。我们的关系建立在优越/自卑之上。

健康的亲密关系、合作、教育，都应该是横向的。但大部分人从小被训练在纵向关系中——父母比孩子高、老师比学生高、上级比下级高。这种训练在每个人心里种下了一种**对优越感的无意识渴望**。

一个真正"超越自卑"的人，**不是比所有人高，是与所有人平等**。这是阿德勒最重要、也最被忽视的一点。

```
自卑的人：
   想"比别人强"
   想"证明自己"
   想"占据更高的位置"

超越自卑的人：
   想"贡献自己的力量"
   想"和别人合作"
   想"在共同体中找到自己的位置"
```

这是为什么阿德勒的体系不是"个人奋斗"的哲学——它是**社会嵌入**的哲学。你不能脱离他人来定义你自己。

### 2.3 "私人的逻辑"vs"公共的意义"

阿德勒另一个概念叫**"私人的逻辑"**（privates Logik）——指一个人内心对自己生活的解释。这个私人逻辑**不是事实**，但它在心理上完全是"真的"。

> 一个孩子相信自己"不被爱"——这个信念可能没有任何现实依据，但**它是真的**——它决定了孩子如何行动。

心理治疗的本质，是帮来访者看到：**私人逻辑不等于现实**。当一个人意识到"我以为我不如别人"只是"我以为"，他就有了改变的可能。

这就是阿德勒的治疗方法——不深入潜意识去"挖掘被压抑的过去"，而是**在当下、在社会情境中、在生活任务中**，让来访者看见自己正在用的私人逻辑。

## 三、生活风格与创造性自我

### 3.1 早期统一性

阿德勒拒绝把人拆成"本我、自我、超我"（弗洛伊德）这种内部结构。他把人看作一个**整体**——一个**统一性**（Einheit）。这个统一性在他五岁前后就基本成型了。

这就是阿德勒著名的**早期统一性原则**：一个人的基本生活方式（Lebensstil; "life style"）、对世界的解释、对自己的定位、对未来的期待——在四五岁时**已经定型**。

```
4-5 岁的生活风格，70 岁时仍在用——只是题材换了。

小时候：在玩伴中感觉自己不够好
长大后：在同事中感觉不够好
再长大后：在家庭里感觉不够好

剧情相同，演员换了。
```

这不是命运论。**统一性是可以被改的，但只有在治疗关系中、在与另一个人的深度对话中，才能被改。**

### 3.2 创造性自我

人不是被动地由过去决定的。阿德勒强调一个概念叫**创造性自我**（schöpferische Ich / creative self）：

> 每个人都在**主动地**塑造自己。不是完全由基因决定的，不是完全由童年决定的，不是完全由社会决定的——人**利用**这些素材，**创造**一个独特的自我。

这个观点让阿德勒成为"人本主义心理学"——尤其是马斯洛（Abraham Maslow）、罗杰斯（Carl Rogers）——的精神先驱。

```
弗洛伊德：人是过去的产物（过去 → 现在）
阿德勒：人是当下的创造者（现在 → 未来）
```

阿德勒不是简单否定过去。他只是把重心从"挖掘过去"移到了**"现在如何用这些素材"**。

### 3.3 生活风格的具体构成

阿德勒所说的"生活风格"包含四个互相关联的成分：

```
┌──────────────────────────────────────┐
│  自我概念     我是谁（在我看来）          │
│  自我理想     我希望成为谁              │
│  世界图像     世界是什么样的（在我看来）     │
│  道德标准     对与错的标准（在我看来）       │
└──────────────────────────────────────┘
         │
         └────── 全部在 4-5 岁时初步定型
```

- 一个孩子觉得"我不被爱"——他的自我概念已经偏斜
- 一个孩子希望"我被全世界仰慕"——他的自我理想已经失衡
- 一个孩子觉得"世界是威胁"——他的世界图像已经阴郁
- 一个孩子觉得"只有做到完美才算好"——他的道德标准已经过严

这四件事在五岁前悄悄定型，并开始**塑造**他未来几十年的人生选择。

**这是为什么童年不是"被决定的"，但童年的视角是会形成"惯性"的。**

## 四、出生顺序与家庭星座

### 4.1 不只是"老大/老二"

阿德勒提出过一种影响深远的人格理论——**出生顺序效应**（birth order effects）。这被后来的研究反复验证与争论，是阿德勒理论里最具争议、也最"接地气"的一部分。

```
长子：
  -  起初是"小大人"，被训练照顾别人
  -  后来弟妹出生，失去"独享父母关注"的位置
  - 容易发展出：责任感、对权威的适应、对失去的敏感
  - 神经症类型：强迫、抑郁、退缩

次子：
  -  从小就有"前面有人"的处境
  - 习惯追赶、竞争
  - 容易发展出：雄心、行动力、对刺激的追求
  - 神经症类型：反叛、躁狂、对失败的不耐

幺子：
  -  全家最小的，常被宠
  - 但也可能被当作"最弱的"
  - 容易发展出：依赖、撒娇、表演性
  - 神经症类型：拖延、退行、自我矮化

独生子：
  -  没有兄弟姊妹
  - 与父母关系极深
  - 容易发展出：早熟、对人际关系的陌生
  - 神经症类型：孤立、完美主义
```

这些是**倾向**，不是命运。同一个位置在不同家庭里的影响完全不同。

### 4.2 家庭星座（Familienkonstellation）

阿德勒后期进一步提出，比出生顺序更重要的是**整个家庭星座**——一个孩子在家庭里和其他成员的相对位置、关系模式、互动历史。

- 你和父亲的关系？
- 你和母亲的关系？
- 你的兄弟姊妹中，谁和你竞争，谁和你合作，谁和你疏远？
- 哪个孩子是"榜样"，哪个是"失败者"，哪个是"被宠爱的"？

**这些角色会在你心里种下剧本：你要成为什么样的人。**

而且——更关键的是——**这种"心理角色"**和实际出生顺序**没有强相关**。家里有个学习最差的孩子，他会内化"我是最差的"角色；家里有个最聪明的孩子，他会内化"我是最聪明的"角色。**位置是物理的，角色是心理的。**

### 4.3 一个临床片段

阿德勒在他的诊所里记录过这样的对话（意译，原文德语）：

> 一个十二岁的男孩，偷窃成瘾，被多次送进少管所。老师和父亲都说"他天生反社会"。
>
> 阿德勒与男孩谈话。男孩说："我弟弟才是家里最好看的、最聪明的、最乖的。我爸爸总是看弟弟。我做什么都没用。"
>
> 阿德勒说："所以偷东西是为了让你爸爸看见你？"
>
> 男孩沉默了一会儿，点头。

这不是"找到病灶"，这是**找到一个可以改写的位置**。阿德勒的治疗不是"教育男孩不要偷"，是**让他看见：他在家庭里被分配的角色，是一个可以被重写的故事**。

## 五、早期记忆：被遗忘的剧本

### 5.1 为什么问最早的记忆

阿德勒最重要的临床工具之一是**问早期记忆**（frühe Erinnerungen）。他不是要"挖掘童年创伤"——他是在问"你给自己编的剧本是什么"。

> 请告诉我你能想起的最早的事。**不是**最戏剧性的，只是**最早浮现**的那一件。

一个人回忆出的"最早的事"通常不是真的最早发生的事——它是一个**被选中的**、对自己**有意义**的场景。**这个选择本身就是诊断。**

### 5.2 三个案例

```
来访者 A：最早记忆是母亲在窗边看远方。
  阿德勒解读：来访者把"母亲是孤独的"作为核心叙事。
  影响：他/她成年后对亲密关系充满警觉，
       害怕自己的伴侣也会"看着远方"。

来访者 C：最早记忆是父亲把他/她举到头顶。
  阿德勒解读：来访者把"父亲是强大的"作为核心。
  影响：他/她成年后崇拜权威，
       或反过来刻意反叛权威。
```

早期记忆不"对"——它们是**心理结构的样本**。它们告诉你：在这个人的心里，世界是什么样的剧本。

### 5.3 阿德勒的治疗对话

这是阿德勒与一位三十岁女性来访者（治疗持续了约一年）的某个片段，意译：

> 来访者："我最近很难专注工作。我总是想起我小时候。"
>
> 阿德勒："你想起哪个'小时候'？"
>
> 来访者："我七岁的时候时。我爸妈妈都出门了。家里很黑。我不知道做什么。"
>
> 阿德勒："当时你想做什么？"
>
> 来访者："我想让他们回来。我坐在楼梯上等。"
>
> 阿德勒："你现在还在等吗？"

这不是修辞——这是诊断点。**这个女性心里有一个模式："我必须等别人来救我。我不能主动。"** 她的工作问题（无法专注、无法做决定）就是这个模式的延伸。

治疗的工作，是让她意识到这个模式，**选择不再使用它**。

这就是为什么阿德勒治疗能见效——**它不是用一堆新理论去"覆盖"患者的旧信念，而是让她在当下的关系里，**看到自己正在使用的剧本，然后自己决定是否改写它**。**

## 六、个体心理治疗：作为方法的理解

### 6.1 治疗师的位置

阿德勒的个体心理治疗（Individualpsychologie）有非常具体的治疗师姿态：

- **平等**：治疗师不是"专家"，不是"医生"，不是"权威"——是**平等的参与者**。
- **关系**：治疗改变主要发生在"治疗关系"本身——治疗师与来访者之间的关系，就是来访者与他人的关系的样本。
- **社会嵌入**：治疗不只是"两个人在房间里谈话"。治疗师要了解来访者的**社会情境**——工作、家庭、朋友、文化——因为所有问题都在这些情境里发生。
- **目标导向**：治疗不是"无止境地挖掘"。它有明确目标：帮助来访者**对生活任务**（Lebensaufgaben）的处理能力增强。

### 6.2 三大生活任务

阿德勒把所有的人生挑战压缩成**三个生活任务**：

```
1. 工作（Beruf / Work）
   我们如何贡献自己的力量到世界中？
   不只是"职业"——是任何形式的"对社会有用的活动"。

2. 友谊（Freundschaft / Friendship）
   我们如何与他人建立平等的关系？
   包括所有非血缘、非性的关系。

3. 爱情（Liebe / Love）
   我们如何与一个特定的人建立亲密关系？
   包括所有长期承诺的关系。
```

任何人如果一个生活任务都处理不好，那里有**自卑感**的痕迹。

```
工作失败 → 我没用 → 自卑感
友谊失败 → 我不被人接受 → 自卑感
爱情失败 → 我不值得被爱 → 自卑感
```

反过来，这三个任务的任何改善，都会**反向**减弱自卑感。这也是阿德勒治疗师经常给来访者的"家庭作业"：不是去回忆童年，而是**主动做一件事——主动联系一个朋友、主动结束一段自我贬抑的关系、主动完成一件有贡献的工作**。

### 6.3 鼓励与解释

阿德勒治疗的两大核心动作是：

```
解释（Deutung）：让来访者"看见"自己正在使用的私人逻辑。
   "你看起来在发火，但我注意到你其实在难过。"
   "你说你想辞职，但你想逃离的可能是某个具体的人。"

鼓励（Ermutigung）：让来访者相信"我有能力改变"。
   不是空洞的"加油"。
   是基于事实的、具体的：
   "你已经一个人生活了三年，按时支付房租。
    你能面对具体的事。你的勇气比你以为的多。"
```

阿德勒反对弗洛伊德的"中立、匿名、不参与"的分析师姿态。他认为这种姿态**本身就是一种冷暴力**——它在重复许多来访者童年时被冷漠对待的经验。

治疗师**必须**温暖、必须参与、必须**相信**来访者的能力。这是为什么阿德勒治疗有时候被叫作"**鼓励的治疗**"**。

## 七、阿德勒的影响与传承

### 7.1 与精神分析的分裂史

阿德勒离开弗洛伊德之后，"个体心理学"作为独立流派生存了下来——但在一段时间里，它被弗洛伊德学派的统治地位所压制。弗洛伊德本人曾形容阿德勒的离开是"对一个被我抚养、给予机会、接纳进我圈子里的人的绝望"。

但 1920 年代以后，阿德勒在欧美各地（尤其是美国）讲学，他的著作被翻译，他的临床方法被许多年轻心理学家采用。1937 年阿德勒去世时，个体心理学已经在欧美有十几个分支机构和培训项目。

他的核心思想——**强调社会、强调未来、强调当下的能动性、强调平等的治疗关系**——正在被另一批人继承。

### 7.2 人本主义心理学

最直接的继承者是 **卡尔·罗杰斯**（Carl Rogers）和 **亚伯拉罕·马斯洛**（Abraham Maslow），他们 1940-1960 年代建立了"人本主义心理学"（Humanistic Psychology），即心理学史上的"第三势力"。

```
第一势力：行为主义（华生、斯金纳）—— 人是刺激-反应机器
第二势力：精神分析（弗洛伊德、阿德勒早期）—— 人是被过去决定的
第三势力：人本主义（罗杰斯、马斯洛）—— 人是自我实现的能动者
```

罗杰斯的**以来访者为中心的治疗**（client-centered therapy）几乎完全采用阿德勒的姿态：
- 治疗师不是权威
- 治疗师的态度是真诚、共情、无条件积极关注
- 治疗的改变发生在"关系"本身

马斯洛的**需求层次理论**也直接呼应阿德勒：自我实现（self-actualization）是超越自卑感的最高需求。

### 7.3 存在主义心理治疗

20 世纪中叶，存在主义心理治疗（Existential Psychotherapy）把阿德勒的遗产与存在主义哲学（萨特、海德格尔、宾斯万格）结合起来。

- **罗洛·梅**（Rollo May）：把阿德勒的"自卑感"翻译成"存在性焦虑"，并加入存在主义维度。
- **欧文·亚隆**（Irvin Yalom）：把阿德勒的"三大生活任务"扩展为"终极关怀"——死亡、自由、孤独、无意义。

这些都是阿德勒流派——不是直接的弟子，是继承者——把同一个核心主题**在新的语言里**重新讲述。

### 7.4 现代心理学中的阿德勒

今天的临床心理学仍然使用阿德勒的几个核心工具：

- **早期记忆访谈**：在人格评估中仍然有效。
- **家庭星座分析**：在家庭治疗、伴侣治疗中广泛使用。
- **生活任务模型**：在生涯辅导、心理教育中作为框架。
- **鼓励治疗**：作为所有"赋能"型心理治疗的基础姿态。

而"积极心理学"（Positive Psychology）、"成长心态"（growth mindset）、"复原力"（resilience）——这些 21 世纪流行的概念——如果你把它们放回阿德勒的框架里看，**它们几乎全是阿德勒的孙子辈**。

## 八、对程序员的几条启示

阿德勒不是工程师，但他描述的"自卑与补偿"、"社会兴趣"、"生活任务"、"创造性自我"，对工程师的工作和职业生活有非常具体的对应。我把这次散步总结成几条。

### 8.1 Imposter Syndrome 是自卑感的当代形态

> **阿德勒**：每一个人都有自卑感，因为它来自"意识到自己的有限"。
>
> **启示**：所谓 Imposter Syndrome（冒名顶替综合征）——"我不配、我不够格、我迟早会被人揭穿"——**不是 bug**。它是 feature。它是**人对自己的有限性的正常感知**。

我们从小被训练出"我必须证明自己"——在我们 5 岁时（也就是生活风格定型的年龄），我们就被比较、被要求、被排进某个角色。

Imposter Syndrome 不是"病"，它是"剧本"。**剧本可以被改写**。

```
老剧本：
  我不够好。我必须证明自己。
  我需要做出惊人的事，才配被看见。

新剧本：
  我确实有些事不够好——所有人都是这样。
  我的价值不取决于"做出惊人的事"。
  我的价值在于"用我能做的，对共同体有所贡献"。
```

第二种剧本不是"鸡汤"。它是阿德勒意义上**社会兴趣**的觉醒。

### 8.2 Senior 工程师的真正角色：横向关系

> **阿德勒**：健康的关系是横向的，不是纵向的。
>
> **启示**：资深工程师不是"比你高的人"，是**和你并排站着、能帮你看到全图的人**。

很多"senior 工程师"被训练成纵向关系的样板——他们必须显得更强、更懂、更快。这种姿态和下属建立的是**自卑-羡慕**的关系，不是合作。

```
纵向姿态的 senior：
  - 我比你懂，你要听我的。
  - 你提的问题不应该问。
  - 你犯错就是不行。

横向姿态的 senior：
  - 我比你多踩过一些坑——我分享一下我的踩坑经验。
  - 你的判断可能是对的——我没看到这一点。
  - 你的失败我也经历过。
```

第二种姿态**也是**资深的体现。但这种资深需要先解决资深自己的自卑感。

### 8.3 三大生活任务：工作 / 友谊 / 爱情

> **阿德勒**：所有的人生问题都能归到这三个生活任务。
>
> **启示**：当你感到生活"不对劲"，问自己——是哪一个任务失败了？

```
工作不对 → 我没有贡献感 → 我对"我有什么用"的怀疑
友谊不对 → 我没有被接受 → 我对"我属于哪里"的怀疑
爱情不对 → 我没有被爱 → 我对"我值不值得被爱"的怀疑
```

很多程序员把工作当全部。但工作只是一个任务——它做得好，**不等于**爱情和友谊就好。一个只有工作、没有友谊和爱情的人，是**半个生活的人**，迟早会"中年危机"——不是因为工作没意义，是因为**生活任务的失衡**。

如果你正在一个领域感到空虚，**先去检查其他两个任务**，不要只盯着那一个去"治标"。

### 8.4 创造性自我 vs 决定论

> **阿德勒**：人不是被过去决定的，是当下的创造者。
>
> **启示**：你的"过去"——你的学历、出身、过去的失败、过去的错误——**不是**你今天的命运。

```
决定的视角：
  我来自小镇 → 我的视野小 → 我的能力有限

创造的视角：
  我来自小镇 → 我看到了真实的中国 →
  → 这种视野给了我独特的产品判断
```

第二种视角不是"自欺欺人"。它是对同一份经历的**重新解释**——而这种重新解释，会改变你未来的选择。

一个能在心里改写剧本的人，是阿德勒意义上的"健康"。

### 8.5 平等的治疗关系：对同事、对下属

> **阿德勒**：治疗师与来访者是平等的。
>
> **启示**：经理与员工、senior 与 junior、设计者与执行者——**真正的合作**建立在横向关系上。

```
纵向管理：
  我有答案，你是执行者。
  你不理解，是你的问题。
  你不接受，是你的态度问题。

横向协作：
  我有一些视角，你有另一些视角。
  我们合作，看哪一个更好。
  我没看到这一点，告诉我。
```

不是所有的纵向关系都是错的。但**过度**的纵向关系，会让被管理的人内化"我不够好"。阿德勒看到了这一点。他把治疗室变成了一个**平等协作的样板**——而这种样板，应该被带到所有的工作关系里。

### 8.6 早期记忆：你的第一个产品

> **阿德勒**：早期记忆告诉我们，你心里在演什么剧本。
>
> **启示**：你做的第一个产品/第一个项目，无论成功或失败，都在"塑造你的剧本"。它告诉未来的你："我能做什么"、"我不能做什么"、"我应该做什么"。

很多人第一次做项目失败后，就在心里形成"我不适合做产品"的剧本——然后十年里都在回避产品角色。这种剧本**不是真的**——它只是早期形成的"自我概念"。

如果你注意到自己"反复在某些事上退缩"，看看是不是某个早期剧本在运作。

### 8.7 鼓励：不是赞美，是基于事实的看见

> **阿德勒**：治疗师的核心动作是"鼓励"，不是赞美。
>
> **启示**：**作为同事/manager，最有效的不是赞美"你做得真好"——是基于事实的看见**。

```
空洞的赞美：
  "你做得真棒！"
  "这个创意太好了！"

基于事实的鼓励：
  "这个方案里的这个点我没看到——你是对的，
   整个项目方案现在更稳了。"
  "你这次主动联系了 X，让我很惊讶——
   因为你之前不喜欢主动联系。"
```

前者让人怀疑。后者让人**真的相信**自己。

## 结语：自卑不是病，超越也不是奖品

1937 年，阿德勒在从都柏林到爱丁堡的演讲途中路上心脏病发作，去世。他那年 67 岁。

他一辈子被弗洛伊德学派的阴影笼罩——在他的晚年，他已经感受到"边缘化"。他在一封信里写道："我没有追求过权力，我只希望把看到的东西说出来。"

但他**确实**说出了别人没看到的东西。在他写下《器官的自卑感》之前的那个世纪，没有人把"自卑感"当作人类心理的根本动力。在他之前的传统心理学，把人看作**欲望的集合**、**本能的容器**、**社会角色的执行者**。

阿德勒说：人是**意义的创造者**。

这个看似简单的判断，是人类认识自己的一次重大转弯。

他在《被讨厌的勇气》（岸见一郎、古贺史健）的章节里被日本作家引用最多——"重要的不是被给予了什么，而是如何利用被给予的东西"。这是阿德勒的回声。

我想用他自己的话来结束这篇文章——这一句话，是他整个理论的灵魂：

> **我们每个人都有不同程度的自卑感，因为我们每个人都希望改进自己。**
>
> **这种自卑感本身不是坏的。它是推动我们追求改善的动力。它决定了我们行为的意义。**
>
> **问题不是"我有没有自卑感"——**
>
> **问题是"我用它做什么"。**
